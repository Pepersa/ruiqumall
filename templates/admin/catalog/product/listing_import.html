上架模板导入

说明： 该页面用于导入固定格式的上架模板 Excel（14 列）： 一级目录 / 二级目录 / 三级目录 / 商品编码 / 品牌 / 产品名称 / 制造商型号 / 容量 / 颜色 / 含税价 / 销售单位 / 包规 / MOQ / MPQ。
系统会按 品牌 + 产品名称 + 制造商型号 去重：相同的三字段视为同一产品系列，自动归到同一 Product 下； 商品编码不同则作为该系列下的不同 SKU。
Product.style_code 由"品牌-产品名-型号"自动拼接生成； 分类按 一级/二级/三级 自动创建（若已存在则复用）。
